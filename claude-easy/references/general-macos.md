# ClaudeEasy 通用诊断 macOS 策略

> 读取路由：内部路由为 `general_computer` 且当前设备是 macOS 时读取本文件。只回答如何取得证据和如何安全执行。

## 能力检测

Computer Use 只有当前会话实际可调用、且能操作目标窗口时才算可用。只会控制浏览器标签页时，不能用来改系统设置或操作其他应用窗口。每次界面操作后立刻回读可见结果；回读失败则该次观察未完成。

没有可用 Computer Use 时，记为界面能力缺失，继续用本文件的系统接口回答仍能回答的问题。

shell、统一日志、进程、文件系统、性能和电源工具都是可用手段，不为它们做启动检测或固定调用清单。某项手段本机不存在、权限不足或调用失败时，只记该手段缺失，改用另一项仍能回答同一问题的本机手段。

## 原场景与界面操作

原场景落在有正常窗口的应用时，Computer Use 可用则按用户实际动作操作一次，并回读窗口标题、对话框和界面状态。

可以安全启动或操作用户要求诊断的普通应用：用 Launchpad、该应用的快捷方式或 `open`。不要套用 Windows 的 Start 菜单、`Get-Process` 或 Event Viewer。Clash 当应用的禁令见 `SKILL.md` 共同安全边界：本文件不得启动、退出、停止、重启或 Computer Use 操作 ClashX Meta。现场问题就是这个客户端本身（崩溃、卡住、占 CPU、窗口打不开）时，只取日志、崩溃报告、进程快照。

## 按问题选择系统证据

只响应 `general-diagnostics.md` 提出的当前取证请求。下列名称是可用手段，不是启动清单。

- 进程：`ps`、`pgrep`；需要窗口时只读“活动监视器”对应行。只取与当前问题直接相关的进程名、PID、CPU、内存或打开文件。
- 文件系统：只在与当前问题有直接关系的路径上用 `ls`、`stat` 或限定该路径树的 `mdfind`。不无边界扫描用户主目录或全盘。
- 性能：`top`、`sample`、`iostat` 的短窗口快照，只取能回答当前问题的字段。
- 电源：问题指向睡眠、唤醒或供电时用 `pmset` 或系统设置的电池/电源页。
- 磁盘：问题指向该卷完整性时，用 `diskutil info` 或磁盘工具只读信息。
- 崩溃报告：只打开 `~/Library/Logs/DiagnosticReports` 或 `/Library/Logs/DiagnosticReports` 中与目标应用和时间窗匹配的报告，只读必要字段。

不读取与当前问题无关的邮件、聊天、钥匙串、浏览器完整历史或文件正文。路径、时间、大小或类型已够回答时，不打开内容字段。

## 日志和历史时间窗

统一日志用 `log show` 或短时 `log stream`，谓词只带当前问题需要的时间窗、进程、子系统或事件类型。不拉全量日志。时间窗来自用户描述或已读记录。

控制台仅在 Computer Use 可用、且 `log` 无法回答同一问题时打开；回读后关掉，不留下持续采集。

通用判断要求建立观察窗口时，范围、开始、停止和清理以 `general-diagnostics.md` 为准。本文件只负责停止 `log stream` 并删除本轮临时输出。不安装 LaunchAgent。

## 权限与安全修改

需要屏幕录制、辅助功能或完全磁盘访问才能继续时，由当前 Computer Use 或系统设置触发系统授权弹窗。不能让用户复制长命令。管理员口令、Touch ID 等系统强制授权照常由系统弹出。不把 `sudo` 当作默认。

修改前记下足够原样恢复的原状态：原文件字节或版本化副本、原偏好值、原进程是否在跑、原设置项。

退出应用、结束进程、删除缓存、修复磁盘、重启、重装和降级按实际数据与恢复风险决定授权，不能为了省事执行：

- 退出应用或结束进程：会丢失未保存工作或中断该应用时先取得授权。ClashX Meta、Mihomo 及其辅助进程仍按 `SKILL.md` 禁止结束。
- 删除缓存：可能丢掉本地数据或登录态时先取得授权；只删已确认对象，并留下可恢复副本或可重建路径。
- 磁盘修复（磁盘工具 First Aid / `diskutil repairVolume`）：会锁定卷或影响数据时先取得授权。
- 重启或注销：会中断未保存工作或其他会话时先取得授权。不得为修复 Clash 或 Mihomo 而重启或注销。
- 重装或降级：会丢掉应用数据或改变版本时先取得授权。不得重装或降级 ClashX Meta。

失败或出现副作用时立即按记录的方法恢复。

## 恢复与复测

恢复写成可在本机执行的步骤：用保存的字节或副本放回原路径、写回原偏好、按记录恢复进程或设置项。不能只记“再改回去”。

复测按通用判断指定的原场景进行。Computer Use 可用时在原界面回读；否则用该应用的结构化状态或同一动作的系统结果。本文件不判断是否已经解决。

## 平台限制

- 工具缺失、权限被拒或 Computer Use 不可用时，向通用判断返回该手段的缺失状态。
- 本文件不提供每次开机都要跑的检查清单。
- macOS 证据和操作只用本机原生能力；同一风险结果不得靠复制 Windows 命令、日志来源或应用行为实现。
